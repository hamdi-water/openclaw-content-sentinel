Flux d'utilisation

Le runtime nominal doit suivre exactement le cahier des charges: OpenClaw execute les etapes 1 a 4, Telegram devient l'interface de controle a l'etape 5, puis OpenClaw publie automatiquement a l'etape 6 apres approbation.

1

Ingestion concurrente

OpenClaw charge le brief actif, lit l'URL concurrente, scrape la page publique, nettoie le texte et produit une synthese exploitable.

2

Recherche tendance

Le run collecte ensuite des signaux zero-cost via RSS, pytrends, SearXNG et les flux publics utiles au sujet.

3

Analyse + generation

OpenClaw et le graphe LangGraph synthetisent la source, les trends, la memoire et le graphe pour produire l'article et les drafts LinkedIn, Facebook et X.

4

Image

L'image est generee localement, puis ajoutee au paquet d'approbation avant toute publication.

5

Telegram natif

Telegram est l'interface operateur complete: preview, `/status`, `/logs`, `/approve`, `/reject`, `/run-now`, et overrides temps reel.

6

Auto-posting

Apres `/approve`, OpenClaw ouvre les profils persistants et publie automatiquement sur LinkedIn, Facebook et X avec preuves et captures.

Commandes essentielles

Ces commandes couvrent le chemin operateur minimal, depuis la verification du setup jusqu'a la publication et au suivi des logs.

1. Verifier le setup

python -m openclaw_content_sentinel.cli doctor
python -m openclaw_content_sentinel.cli compliance-report
python -m openclaw_content_sentinel.cli runtime-status

2. Preparer l'entree journaliere

python -m openclaw_content_sentinel.cli set-daily-input --prompt-file .\config\daily_prompt_template.md --competitor-url "https://www.rnz.co.nz/news/national/590645/health-nz-staff-told-to-stop-using-chatgpt-to-write-clinical-notes" --targets linkedin facebook x

3. Lancer le run

python -m openclaw_content_sentinel.cli scheduled-run

4. Suivre le run

python -m openclaw_content_sentinel.cli status --json

5. Valider Telegram

/status <run_id>
/logs <run_id>
/approve <run_id>
/reject <run_id>

6. Publier ou tracer

/publish <run_id>
python -m openclaw_content_sentinel.cli browser-publish-all --run-id "<run_id>" --retries 1
