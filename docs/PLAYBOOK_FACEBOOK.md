# Playbook: Facebook Publication

## Protocol §35.2

1. **Authentication**: Use the `facebook` browser profile.
2. **Navigation**: Navigate to the target Page or Profile URL.
3. **Draft Injection**:
   - Open the composer.
   - Inject the draft from `drafts/facebook.md`.
4. **Media Attachment**:
   - Use the "Photo/Video" button.
   - Upload `media/social_card.png`.
5. **Quality Check**: 
   - Ensure the layout is correct for mobile and desktop.
6. **Submission**: Click "Post" or "Publish".
7. **Verification**: Confirm the post appears in the feed. Capture screenshot.

## Fallback Mode
Manual intervention via the Telegram cockpit if page structure changes.
